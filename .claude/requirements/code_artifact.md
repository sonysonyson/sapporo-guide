## 2. 기획 배경 및 목적 (Overview)
* **개발 배경:** 사용자가 특정 여행지의 핵심 정보, 추천 코스, 현지 팁을 한눈에 파악하고 일정을 계획할 수 있도록 돕기 위함.
* **핵심 목표:** 
  * 직관적인 UI를 통한 여행지 탐색과 가이드 내 추천 장소
* **타겟 디바이스:** Mobile App (iOS / Android), Mobile Web (반응형 대응 여부 기재)

## 4.0.1. 삿포로 기본 정보

**(1) 위치** 

✔️ 일본 홋카이도의 중심 도시. 인구 약 200만 규모이며 사계절이 뚜렷하고 겨울에는 눈이 많이 내립니다. 

✔️ 한국과는 비행기로 약 3시간 30분 정도 거리에 위치해있으며 서울, 청주, 부산 등의 국제공항을 이용해 이동이 가능해요

✔️ 여름/겨울 성수기 표는 평일 4/50만원대, 주말 6-70만원대가 평균이며 평수기는 20-30만원대로 방문이 가능합니다.

⏭️ 항공권 할인받기 (click)

~ 11/30까지 할인코드: **3HAFLT3** 적용 가능

**(2) 공항 이동**

✔️ 신치토세공항에서 삿포로역까지 JR 쾌속 에어포트로 약 37분

✔️ 공항버스로 시내까지 약 70분 정도이며, 공항버스 탑승시 국내선으로 이동하여 탑승권장 (선착순 탑승으로 자리 없으면 대기해야함)

✔️ 삿포로역 숙소 예약시 JR기차, 오도리 or 스스키노 숙소 예약시 리무진 추천

**(3) 시내 교통**

IC카드, 교통패스, 일반 컨택리스 카드 사용 가능

**(4) 여행 팁**

삿포로역–오도리–스스키노는 지하 보행공간으로 이어지는 구간이 있어 추운 날 이동에 편리합니다. 

## 4.0.2. 가봐야 할 명소

### 삿포로 시내

- **오도리공원·삿포로 TV타워** — 도심 산책과 계절 행사 관람의 중심.
- **삿포로 시계탑·홋카이도 구청사(붉은 벽돌 청사)** — 삿포로의 역사적 건축물과 사진 명소.
- **스스키노·다누키코지 상점가** — 저녁 식사, 쇼핑, 야간 산책.
- **니조시장** — 해산물 덮밥과 아침 식사 후보. 영업시간과 휴무는 방문 전 확인.
- **삿포로 맥주박물관·맥주원** — 맥주 역사 전시와 징기스칸 식사.
- **홋카이도 신궁·마루야마공원** — 신사와 숲길을 함께 둘러보기 좋은 코스.
- **모이와산 전망대** — 날씨가 맑은 날 야경 코스로 추천. 로프웨이 운행 여부 확인.
- **시로이코이비토 파크** — 과자 테마파크·기념품·가족 코스.

### 근교 여행지

- **오타루:** 운하, 사카이마치 거리, 오르골당, 유리공방, 스시·디저트. 삿포로에서 당일치기로 다녀오기 좋아요.
- **비에이·후라노:** 꽃밭·설경·청의호수 등 계절 풍경 중심. 이동 거리가 길어 하루를 따로 잡는 편이 좋습니다.
- **조잔케이:** 온천과 계곡 풍경을 즐기는 휴식형 근교 일정.
- 노조리베츠 : 유황온천과 지옥계곡 동물원 등 다양한 체험을 하며 설경을 감상하기 좋아요
- **니세코:** 스키·아웃도어가 목적이면 고려하되, 이동과 체류를 감안해 숙박 포함 여부를 검토하세요.

## 4.0.3. 추천 일정

### 2박 3일 — 삿포로 시내 중심

- **1일차:** 신치토세공항 → 숙소 → 오도리공원·TV타워 → 시계탑·붉은 벽돌 청사 → 스스키노 저녁
- **2일차:** 니조시장 아침 → 삿포로 맥주박물관 또는 마루야마공원·홋카이도 신궁 → 모이와산 야경
- **3일차:** 삿포로역 주변 쇼핑·간식 → 공항 이동

**✔️ 추천 대상:** 삿포로 첫 방문, 이동을 줄이고 시내 맛집과 쇼핑에 집중하고 싶은 경우

### 3박 4일 — 삿포로 + 오타루

- **1일차:** 도착 후 오도리·시계탑·스스키노
- **2일차:** 오타루 당일치기 — 운하, 사카이마치, 오르골당, 해산물 점심
- **3일차:** 맥주박물관 또는 마루야마·홋카이도 신궁 → 저녁에 모이와산
- **4일차:** 여유 있게 쇼핑·공항 이동

**✔️ 추천 대상:** 대표 명소와 근교 한 곳을 균형 있게 보고 싶은 경우. 홋카이도 공식 예시 일정도 삿포로와 오타루를 함께 묶습니다. 

✔️ 오타루도 야경이 아름답고 구경할 곳이 많아 1박 가능하다면 추천드리고 싶습니다. 공항 → 오타루 1박하며 전망대 루트까지 다녀오세요.

### 4박 5일 — 삿포로 + 근교 2곳

- **1일차:** 도착·체크인 → 오도리·스스키노
- **2일차:** 오타루 당일치기
- **3일차:** 비에이·후라노 버스투어 또는 조잔케이 온천, 노보리베츠 온천 중 하나 선택
- **4일차:** 마루야마·홋카이도 신궁, 시로이코이비토 파크, 모이와산 중 취향에 맞춰 선택
- **5일차:** 삿포로역 주변 쇼핑·공항 이동

**✔️ 추천 대상:** 근교 투어를 넣되 삿포로 시내도 여유 있게 즐기고 싶은 경우

**✔️ 주의:** 비에이·후라노는 장거리 이동과 계절·날씨 영향을 크게 받으므로 투어 일정과 취소 규정을 확인하세요.

## 4.0.4. 추천 숙소 지역

| 지역 | 이런 여행자에게 추천 | 장점·유의점 | 숙소 후보 |
| --- | --- | --- | --- |
| **삿포로역** | 공항 이동·JR 근교 이동이 중요 | 공항 열차와 쇼핑 접근성이 편리. 버스투어 집결지는 상품별로 확인 | 케이한 호텔 삿포로 |
| **오도리공원** | 첫 방문·도심 관광 중심 | 삿포로역과 스스키노 사이에 있어 이동 균형이 좋음 | 라젠트 스테이 삿포로 오도리 |
| **스스키노** | 맛집·야간 활동·쇼핑 중심 | 식당과 번화가가 가까움. 밤늦은 시간의 거리 분위기를 고려 | 카락사 호텔, 도미인, 베셀 호텔 캄파나, 다이와 로이넷 |
- 숙소 후보와 예약 링크는 삿포로 여행 정보에 모아둔 목록을 참고하세요. 요금·객실·시설은 예약일 기준으로 다시 확인하세요.

- 투어는 **가격만 비교하지 말고** 출발 장소, 실제 방문지, 현지 체류시간, 식사 예약 방식, 사진 서비스, 취소 마감일을 함께 비교하세요.
- 저장해둔 업체별 노선·가격은 삿포로 버스투어 정리본에서 확인하세요. 메모에 적힌 가격과 운행 조건은 작성 시점의 정보일 수 있으니 현재 판매 페이지에서 재확인하세요.

### 4.2. 핵심 요약 및 퀵 메뉴 (Summary & Quick Menu)
* **여행 요약 카드:** 추천 계절, 권장 일정(예: 3박 4일), 예상 경비 수준, 주요 테마 태그(`#맛집탐방`, `#힐링` 등) 노출.
* **앵커 탭(Anchor Tab):** `[개요]`, `[추천 코스]`, `[필수 체크리스트]`, `[현지 팁]` 클릭 시 해당 섹션으로 부드럽게 스크롤 이동.

### 4.3. 추천 코스 및 지도 연동 (Recommended Itinerary & Map)
* **일차별 필터:** `Day 1`, `Day 2`, `Day 3` 가로 스크롤 칩(Chip) 제공. 선택 시 하단 리스트 및 지도 마커 갱신.
* **미니 지도 뷰 (Map View):**
  * 선택된 일차의 장소(POI)들을 핀(Pin)으로 표시하고 이동 경로(Polyline) 연결.
  * 지도 영역 클릭 시 전체 화면 지도 뷰로 확장.
* **장소 카드 리스트:**
  * 노출 정보: 순서 번호, 장소명, 카테고리, 간단한 추천 사유(최대 2줄), 썸네일.
  * **인터랙션:** 카드 클릭 시 장소 상세 바텀시트(Bottom Sheet) 노출 / `[+ 일정담기]` 버튼 클릭 시 내 여행 일정 선택 모달 호출.

### 4.4. 하단 플로팅 액션 버튼 (Floating Action Button)
* **버튼명:** `이 가이드 코스로 일정 만들기`
* **동작:** 클릭 시 로그인 여부 체크 $\rightarrow$ 비로그인 시 로그인 유도 팝업 $\rightarrow$ 로그인 상태일 경우 '내 일정'에 해당 가이드의 전체 코스가 복사되어 생성됨.

## 5. 데이터 및 API 요구사항 (Data & API)
* **필요 API 목록:**
  * `GET /api/v1/guides/{guideId}` : 가이드 기본 정보, 에디터 정보, 섹션별 콘텐츠 조회
  * `GET /api/v1/guides/{guideId}/courses` : 일차별 추천 장소(POI) 목록 및 위경도 좌표 데이터
  * `POST /api/v1/users/bookmarks` : 가이드 북마크(찜) 토글 처리
  * `POST /api/v1/itineraries/copy` : 가이드 코스 기반 내 일정 일괄 생성

## 6. 예외 처리 및 엣지 케이스 (Edge Cases)
* **네트워크 오류 / 데이터 로딩 실패:** 재시도(Retry) 버튼이 포함된 에러 화면 노출.
* **장소(POI) 영업 종료/삭제 상태:** 가이드 내 포함된 장소가 폐업 등으로 비활성화된 경우, 리스트에서 회색 처리(Dimmed) 및 `'운영 종료된 장소입니다'` 뱃지 표기 (일정 담기 비활성화).
* **비로그인 사용자 접근:** 열람 및 공유는 모두 허용하되, `북마크` 및 `일정 담기` 클릭 시 로그인 화면으로 이동 후 원래 화면으로 복귀(Redirect).

## 2. 해석·결정 사항
- **4.2 앵커 탭 구성 변경**: 요청서의 `[개요][추천 코스][필수 체크리스트][현지 팁]` 대신 4.0.x 콘텐츠 순서에 맞춰 7개 탭으로 구성 (4.0 우선 원칙).
- **추천 일정 = 추천 코스**: 4.0.3 일정 3종을 4.3 Day 필터·지도와 통합. 기본 선택은 요약 카드의 권장 일정인 3박 4일.
- **"A 또는 B" 일정**: 대안 장소는 `택1` 뱃지 + 회색 핀, 경로(Polyline)에서는 제외. 하루 전체가 선택형(4박5일 3·4일차)이면 경로 미표시 + 안내 문구.
- **"숙소" 단계**(2박3일 1일차)는 특정 장소가 아니므로 코스 POI에서 제외.
- **오타 정정**: 요청서 "노조리베츠" → "노보리베츠". 항공권 "4/50만원대" → "40~50만원대".
- **표 → 카드**: 숙소·투어·맛집 표는 모바일 폭에서 가독성을 위해 카드형으로 변환.
- **썸네일**: 실제 이미지가 없어 카테고리 이모지 아이콘으로 대체 (이미지 URL 주어지면 `coverImage`/POI에 필드 추가).
- **북마크 버튼**: 5·7장에 북마크 API/로그가 있어 네비게이션 바에 추가.
- **로그인**: 실제 인증이 없어 데모 로그인 모달로 대체 (localStorage `sg.loggedIn`).
- **작성일·조회수·POI 좌표**: Mock 값. 좌표는 대략적 위치.

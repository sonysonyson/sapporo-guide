- **추천 일정 = 추천 코스**: 4.0.3 일정 3종을 4.3 Day 필터·지도와 통합. 기본 선택은 요약 카드의 권장 일정인 3박 4일.
- **"A 또는 B" 일정**: 대안 장소는 `택1` 뱃지 + 회색 핀, 경로(Polyline)에서는 제외. 하루 전체가 선택형(4박5일 3·4일차)이면 경로 미표시 + 안내 문구.
- **"숙소" 단계**(2박3일 1일차)는 특정 장소가 아니므로 코스 POI에서 제외.
- **오타 정정**: 요청서 "노조리베츠" → "노보리베츠". 항공권 "4/50만원대" → "40~50만원대".

- **썸네일**: 실제 이미지가 없어 카테고리 이모지 아이콘으로 대체 (이미지 URL 주어지면 `coverImage`/POI에 필드 추가).
- **북마크 버튼**: 5·7장에 북마크 API/로그가 있어 네비게이션 바에 추가. 로컬 저장.

  - 한계: 기기·브라우저 간 동기화 없음, 브라우저 데이터 삭제 시 사라짐 → 화면에 안내 문구 노출, 내보내기로 보관.

## 4. 항공권 할인 카드 정책 (2026-11-22 확정)
- 날짜 기준: **한국시간(KST, UTC+9)**. 보는 사람의 기기 시간대와 무관 (`todayKST`, `daysLeftKST`, `isExpiredKST`)

## 6. 지도: Google Maps 전환 (2026-11-22)
- 사유(사용자): 사용자들이 Google 지도에 익숙하고, 기존 지도는 확대 시 위치 가늠이 어려움
- `js/map.js` MapKit: 공급자 Google Maps JavaScript API(Advanced Marker + Polyline) → 실패 시 Leaflet/OSM → SVG
- 유지 기능: 번호 핀(택1 회색·운영 종료 연회색), 같은 좌표 라벨 병합, 점선 경로(택1 제외, 선택형 날은 없음), fitBounds(최대 줌 15), 미니 지도 조작 불가 + 클릭 시 전체 화면, 전체 지도 핀 클릭 → 장소 시트, 핀 툴팁(장소명)
- 미니 지도: gestureHandling none, UI 숨김 / 전체 지도: greedy 제스처, 줌·스트리트뷰 컨트롤
- 지도 라벨: language=ko, region=KR
- 추가: 장소 시트 "Google 지도에서 보기", 전체 지도 상단 "Google 지도로 경로 보기"(해당 Day 경로, 택1 날은 숨김) — Maps URLs, 키 불필요
- POI 데이터에 `gq`(Google 검색용 일본어 장소명) 추가
- 트래킹: `click_open_google_maps` (type: place/route)
- 현재 `googleApiKey` 미입력 → 화면 지도는 OSM, Google 링크만 동작
- (2026-11-22 버그 수정) 지도 컨테이너(`.mini-map`, `.fullmap__map`)는 `isolation: isolate; z-index: 0` 로 쌓임 맥락을 격리해야 함. 지도 라이브러리 내부 z-index(Leaflet 400~1000)가 새어 나와 작은 지도가 전체 화면 지도·바텀시트·모달·토스트 위로 올라오던 문제. 지도 공급자를 바꾸거나 새 지도 영역을 추가할 때도 동일하게 적용할 것

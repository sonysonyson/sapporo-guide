## 2026-11-22 · 세션 1 (계속) — '지도 크게 보기' 시 이전 지도가 겹쳐 보이는 버그

**사용자 요청 (원문)**
> google 지도말고 '지도 크게 보기' 기능을 사용했을 때 그 전 화면에서 보였던 지도가 그대로 떠있는 경우가 있는데 수정하도록 한다.

**재현 (헤드리스 Edge + DevTools 프로토콜로 실제 클릭)**
- 날짜 변경·창 크기 변경 후 열기 → 정상 (데이터 갱신 문제 아님)
- 작은 지도가 화면에 보이는 위치에서 '지도 크게 보기' → 전체 화면 지도 한가운데에 작은 지도가 그대로 떠 있음 (재현 성공)

**원인**
- 지도 라이브러리 내부 레이어 z-index(400~1000)가 작은 지도 컨테이너에 갇히지 않고 페이지 전체 기준으로 계산됨
- → 전체 화면 지도(z 90), 바텀시트(100), 토스트(200)보다 위에 그려짐. 작은 지도가 화면에 보일 때만 발생해 "경우가 있다"로 나타남

**수정**: `css/style.css` — `.mini-map`, `.fullmap__map` 에 `isolation: isolate; z-index: 0`

## 2026-11-22 · 세션 1 (계속) — Q&A: Google Maps 할당량을 조정할 수 없음

**사용자 질문 (원문)**
> 할당량을 조정할 수 없다는데 이미 제한이 걸린건가?

**확인 결과 (Google 공식 문서 기준, 2026-11-22)**
- 제한이 걸린 것이 아님. Maps JavaScript API 기본값은 분당 한도(프로젝트당 분당 30,000 지도 로드, IP당 분당 300)뿐이고 일일 상한은 기본으로 없음
- 지도 로드는 Dynamic Maps SKU로 과금. 월 무료 사용량은 10,000회 (가격표 기준, 변경될 수 있어 실시간 가격 페이지 확인 필요)
- 일일 상한 = Google Maps Platform > 할당량에서 일일 할당량을 낮추는 것이 공식적인 강제 상한 방법. 권장 값 = 월 무료 사용량 ÷ 31 (10,000 → 하루 322)
- 예산(Budget)은 알림만 하고 사용을 막지 않음
- 조정 불가 원인 후보: 분당 시스템 한도 행을 보고 있음 / 일일 행이 목록에 없음 / 행 체크박스 미선택 / 할당량 수정 권한 부족 → 화면의 정확한 문구를 받아서 다시 확인하기로 함
- 코드 변경 없음

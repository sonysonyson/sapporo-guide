## 2026-11-22 · 세션 1 (계속) — 추천 일정 지도를 Google Maps로 전환

**사용자 요청 (원문)**
> 추천 일정에서 나오는 '지도' 기능을 google map에서 지원 api로 전면 수정할 수 없나? 기존에 제공되는 위치 마커라던지 마커와 마커 사이에 선을 긋는 기능 등등 유지를 했으면 좋겠다. 이유는 다른 사용자들이 google map에 익숙해져있고 해당 지도를 확대해서 봤을 때는 위치 가늠을 하기가 어렵기 때문에 사용성이 불편한 문제가 있다.

**수행 내용**
- `js/map.js` 신규: Google Maps JS API 공급자 (번호 핀 = Advanced Marker, 점선 경로 = Polyline) + OSM/SVG 자동 대체
- `js/config.js`에 `MAP_CONFIG` (API 키, Map ID, 언어/지역)
- `app.js` 지도 코드를 MapKit 호출로 교체, 공급자 전환 시 자동으로 다시 그림
- Google 지도 바로가기: 장소 시트 "Google 지도에서 보기", 전체 지도 "Google 지도로 경로 보기" (키 불필요)
- POI에 일본어 검색어 `gq` 추가

**검증**
- Node: 링크 URL 생성 확인, 키 없을 때 대체 경로 확인
- 헤드리스 Edge: 키 없음 → OSM 정상 / 잘못된 키 → Google 스크립트 실제 로드 후 InvalidKeyMapError 감지 → OSM 자동 전환·핀 정상 표시
- **유효한 키로 Google 지도가 실제 그려지는 화면은 키가 없어 미확인**

**미결**: 사용자가 Google Cloud API 키(결제 계정 필요) 발급 후 `MAP_CONFIG.googleApiKey` 입력
